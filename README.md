# Wishmory

Native SwiftUI MVP for a local gift-memory and wishlist. Open Wishmory.xcodeproj in Xcode, select an iOS simulator, and run.

All data uses SwiftData on the device. There are no accounts, cloud services, analytics, contact importing, or network requests. Photos, notifications, JSON backup/import, strict no-backup exclusion, automated tests, and app-icon assets remain deferred for the next production pass.
